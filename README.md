# 📩 Contact Form using HTML

A simple and responsive **Contact Form** built using **pure HTML**. This project demonstrates how to create a structured form with various HTML form elements such as text fields, email input, dropdown menus, text areas, radio buttons, checkboxes, and a submit button.

## 🚀 Features

* Full Name input field
* Email input with built-in validation
* Subject dropdown menu
* Multi-line message textarea
* Required field validation
* Minimum message length validation
* Radio buttons for selecting how the user found the website
* Newsletter subscription checkbox
* Submit button
* Semantic HTML structure using:

  * `<header>`
  * `<main>`
  * `<footer>`
  * `<form>`
  * `<fieldset>`
  * `<legend>`
  * `<table>`

## ▶️ How to Run

1. Clone this repository.

```bash
git clone https://github.com/your-username/contact-form.git
```

2. Open the project folder.

3. Open `index.html` in any modern web browser.

## ⚠️ Note

The form's `action` attribute currently points to:

```html
https://example.com/contact
```

This is only a placeholder URL. Since it is not a real backend endpoint, submitting the form may redirect to a page that does not process your data. To make the form functional, connect it to your own server or a form handling service.
